How do I check my website against the OWASP Top 10?

Run a free scan that maps every finding to OWASP Top 10, PCI-DSS v4, and ASVS automatically.

OWASP 2017/2021/2025PCI-DSS v4ASVSA–F grade + badge
Short answer: Run webscan scan yourdomain.com. Every finding — from missing security headers to version-based CVEs — carries a CWE and is mapped to the relevant OWASP Top 10, PCI-DSS v4, and ASVS control, viewable as its own compliance report.

The command

webscan scan yourdomain.com -f html -o report.html
# then open the Compliance tab, or in the web UI: /report/<id>/compliance

What gets mapped

  • OWASP Top 10 — 2017, 2021 and 2025 editions
  • PCI-DSS v4 — relevant requirement categories
  • OWASP ASVS — relevant verification requirements
  • CWE — on every individual finding

Findings also roll up into an overall A–F security grade with a shareable SVG badge (/report/<id>/badge.svg) you can drop into a README or internal dashboard.

Where this fits in a real workflow

Run it once to baseline, then schedule it to re-run daily or weekly — you'll only be alerted when a scan surfaces a genuinely new finding compared to the last run, not every time the same known issue re-appears.

Frequently asked questions

What does the compliance mapping actually map to?
Every finding carries CWE, and is mapped to OWASP Top 10 (2017, 2021 and 2025 editions), PCI-DSS v4, and OWASP ASVS where applicable — viewable as a dedicated compliance report per scan.
Is this a compliance certification?
No. It's a mapping that shows which control categories your findings fall under, useful for prioritising remediation and for internal audit prep — not a substitute for a formal PCI-DSS assessment or ASVS certification.
Does it also give me a letter grade?
Yes — each website scan gets an A–F security grade with a shareable SVG badge you can embed in a README or status page.
