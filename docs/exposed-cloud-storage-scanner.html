Cloud exposure

How do I check if I have an exposed S3, GCS, or Azure storage bucket?

Run a free scan that guesses bucket names from your domain and checks each one for public read access.

AWS S3Google Cloud StorageAzure BlobNo credentials needed
Short answer: Run webscan run cloud yourcompany.com. It guesses likely bucket names (yourcompany, yourcompany-assets, yourcompany-backup, etc.) across AWS S3, Google Cloud Storage and Azure Blob, and flags any that are publicly listable.

The command

webscan run cloud yourcompany.com -f html -o buckets-report.html

Why open buckets keep happening

Default-private bucket policies get loosened for a one-off integration, a static-site deploy, or a "just for testing" share — and never get locked back down. Because bucket names are global and guessable, a public bucket under your company's name is one of the easiest things for an outsider to stumble onto.

What good looks like

  • Bucket policy / ACL denies public s3:ListBucket and public object read by default.
  • Static site or CDN buckets are served only through CloudFront/Cloud CDN with Origin Access Control, never directly.
  • Backups and logs live in a separate, non-guessable-named bucket with versioning and access logging on.

Frequently asked questions

How does it find my buckets without an API key?
It generates likely bucket names from your domain (and common suffixes/prefixes) and checks whether each one resolves to a public S3, GCS or Azure Blob endpoint with world-readable listing — no cloud credentials required, because it's testing from the outside, same as an attacker would.
Will it find every bucket?
No — it's a heuristic, name-based guesser, not an account enumeration tool. It catches the common naming conventions (company name, company-assets, company-backups, etc.) but can't find a bucket with a truly random name.
What should I do if it finds an open bucket?
Immediately restrict the bucket policy / ACL to private, audit what was in it, and rotate any credentials or sensitive data that may have been exposed.
